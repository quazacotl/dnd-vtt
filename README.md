# Серебряный дозор — локальный DnD VTT

Первые два рабочих среза приложения с нуля: чат → проверка намерения → игровые правила → атомарное сохранение → анимация. Поддерживаются атака, перемещение и подход с атакой. Это ограниченный прототип D&D 5e 2014, не полный MVP исходного ТЗ.

## Запуск

На этом компьютере зависимости уже установлены. Откройте `start.cmd` либо выполните из папки приложения:

```powershell
npm.cmd run dev
```

Адрес: `http://localhost:5174/`. Сервер слушает localhost. Для запуска после переноса нужны Node.js 24 LTS версии 24.15.0 или новее и `npm.cmd ci`. Lock-файл включён в проект.

`start.cmd` при наличии использует bundled Node Codex 24.19.0, поскольку системный Volta shim оказался недоступен в sandbox. Он не меняет системную установку Node и не устанавливает зависимости автоматически.

## Проверочный сценарий

1. Нажмите «Создать демо-кампанию».
2. Начните бой. Если первым ходит гоблин, нажмите «Завершить ход», чтобы перейти к Лираму.
3. На ходу Лирама выберите его токен и кликните клетку 3,5 либо введите «Иду на 3,5». Движение расходуется, действие остаётся доступным.
4. Введите «Подхожу к гоблину и атакую мечом». Движок сначала проверит весь путь и возможность атаки, затем применит оба действия одной записью. Обычная атака без подхода: «Атакую гоблина мечом».
5. Проверьте путь, оставшееся движение, бросок атаки, HP, результат в чате и анимацию. Возможен промах — броски случайные.
6. Перезагрузите страницу: позиции, ресурсы хода и история сохраняются.
7. Нажмите «Повторить анимацию»: HP, движение, броски и ревизия не изменяются.

Участники управляются вручную: автоматических ходов противника нет. Parser использует активного участника, а не выбранный для просмотра токен. Повторная атака после расхода действия отклоняется.

## Qwen

В «Настройках» выберите Qwen / совместимый API, укажите ключ при необходимости и нажмите «Проверить API». Проверка отправляет тестовое описание атаки и не изменяет игру. Затем нажмите «Применить»: успешная проверка сама по себе не переключает настройки чата.

Действующие настройки и ключ из памяти синхронизируются с игровым controller при hot reload. После полной перезагрузки страницы ключ требуется ввести снова, если сохранение ключа выключено.

- Base URL: `https://ai.hexteam.tech/v1`.
- Модель: `Qwen3.8-27B-Abliterated`.
- Предполагаемый endpoint: `POST /chat/completions` относительно Base URL.
- Ключ находится в памяти; сохранение в localStorage включается только отдельной опцией.
- Ответ проверяется схемой; LLM не определяет броски, попадание, урон или HP.

В dev-режиме запросы к настроенному Base URL идут через Vite proxy: браузер обращается к `/llm-api/chat/completions`, Vite пересылает запрос в `https://ai.hexteam.tech/v1/chat/completions`. Ключ передаётся в Authorization как раньше; в конфигурации Vite он не хранится. Существующие настройки с этим Base URL работают без повторного сохранения.

После изменения Vite-конфигурации перезапустите `start.cmd` / `npm.cmd run dev`. Proxy доступен только в dev-режиме. Для статической production-сборки и другого Base URL запрос остаётся прямым и требует CORS на стороне сервиса. Отдельный backend приложения не добавлен.

Без ключа сервис требует авторизацию; успешная интерпретация настоящей моделью пока не подтверждена.

Локальный parser выбран по умолчанию и позволяет проверить весь игровой сценарий без модели. При отказе Qwen режим не переключается скрыто: выберите локальный parser явно.

## Что поддерживается

- Подготовленная карта, токены, выбор участника и его карточка.
- Непроходимые стены и занятые клетки, кратчайший путь, подсветка доступного движения и анимация пути.
- Перемещение по клику и по координатам в чате. Координаты от нуля показаны на карте.
- Скорость по умолчанию 30 футов; шаг, включая диагональный, стоит 5 футов. Срезать закрытые углы нельзя. Бюджет сбрасывается в начале хода.
- Атомарный подход с атакой: невозможная атака не приводит к частичному перемещению или броскам.
- Инициатива, раунды и ручной переход хода.
- Одна атака оружием за действие: дистанция, d20, natural 1/20, крит, урон и временные HP.
- Завершение боя после поражения стороны.
- Сохранённые события, исходный текст действия и визуальный replay.
- Отказы при неизвестной цели, неверной дистанции и израсходованном действии.
- IndexedDB с транзакцией и дедупликацией commandId. Повтор записи после ошибки использует прежние броски.

## Ограничения

Редакторы, создание произвольных кампаний, заклинания, LSS/JSON-импорт, undo и редакция 2024 относятся к следующим срезам. Opportunity attacks, сложная местность и линия видимости атаки пока не рассчитываются. Дальность атаки — max(|dx|, |dy|) × 5 футов.

Старые сохранения читаются с совместимыми значениями скорости, движения и препятствий; HP, порядок ходов и журнал не сбрасываются. Replay следует записанному пути, не вычисляя его снова. При ошибке GPU анимация прекращается, игра остаётся сохранённой и доступной через чат.

Данные привязаны к браузеру и origin, включая порт. Экспорт пока отсутствует. Не очищайте данные сайта, если хотите сохранить демо. При повреждении формата приложение показывает ошибку и не стирает запись.

## Проверки

```powershell
npm.cmd test -- --run
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run format:check
npm.cmd run build
```

Тесты проверяют правила, IndexedDB, parser, отмену/таймаут, повтор записи, восстановление исходных сообщений и экран кампании. WebGL проверяется отдельно в браузере; компонентный тест страницы подменяет только hook сцены.

## Устройство

`src/pages/campaign` содержит интерфейс, hooks и самостоятельный игровой сценарий. Чистый движок не зависит от React/PixiJS. Репозиторий централизует хранение, адаптеры parser заменяемы. PixiJS загружается отдельным модулем. URL выбранного участника переживает reload; неправильный ID имеет безопасное значение по умолчанию.

Адреса и параметры окружения находятся в `src/shared/config.ts`, маршруты — в `src/shared/config/routes`. Секреты в эти файлы не включаются.
